settime -- set the PicoCalc's clock from the internet
=====================================================

Test build. Needs a PicoCalc with a Pico 2 W (RP2350W), UF2
Loader 2.3 or later, and WiFi on 2.4 GHz with WPA2.

The PicoCalc has no battery-backed clock. settime gets the
time from an NTP server and puts it in the RP2350's always-on
timer, which keeps running when you switch from one program to
another. Every program run after settime can read it (see
picocalc_clock.h) until the power is switched off.


INSTALL
-------
1. Copy settime.uf2 into the pico2-apps folder.
2. Settings: settime reads /settime.cfg, or if that isn't
   there, /virtualt/virtualt.cfg. Same format either way:
     ssid=YourNetwork
     password=YourWiFiPassword
     tz=PST8PDT,M3.2.0,M11.1.0
     ntp=pool.ntp.org
   (tz and ntp are optional; those are the defaults.)
3. Run settime from the boot menu or the shell.


WHAT IT DOES
------------
Clock not set yet:  joins WiFi, asks NTP, sets the clock,
                    shows the time, returns to the shell.
Clock already set:  shows the time and returns at once.
                    Press N while it says "Already set" to
                    fetch the time again anyway.
Something failed:   says what, and waits for a key.

The clock lasts until the PicoCalc is switched off (or the
batteries come out). Run settime again after power-on.


RUNNING IT AUTOMATICALLY
------------------------
It can go in Blair Leduc's PicoCalc Shell startup script
(AUTOEXEC.BAT or /etc/profile). But those run every time the
shell starts -- including every return from a program -- and
the shell has to write settime into flash again whenever a
different program ran last. Until the shell can check the
clock for itself, running settime by hand after power-on is
the quicker way.


PROGRAMS THAT USE THE CLOCK
---------------------------
VirtualT sets and reads it. Programs can use picocalc_clock.h
(MIT licence) -- one call at startup:
    picocalc_clock_load();
sets the program's own time()/localtime() from the shared
clock, if it is set.
